# 《寻妈记》中文中的少量英语用法备注

按用户确认的范围，备注只解释英文表达与中文含义之间的理解缺口。只对固定搭配、俚语、特殊句式或临时造词补一条短括注，直接接在原有 zh 文本末尾；不新增区域、字段、按钮、剧情复述、笑点说明或人物动机分析。普通句子不加，同一表达在一课内重复出现时不重复注释。能改译文说清楚的，直接改译文。

例如 call it a day 解释结束工作的原义和本句结束关系的用法；take … off your hands 解释替对方接手物品；can’t not 解释“无法不”；unterrible 解释临时加 un- 的构词。粗俗俚语只标明词义和语域，不展开生理或剧情解释。get it on 的译文明确为“上床”，overrated 直接译为“被看得太重”，up yours 修正为自然的骂人话表达；不为这些修改加额外分析段落。
