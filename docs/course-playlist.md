# 课程列表播放与长按切课

2.1.17 在练习面板的“循环范围”中提供关闭、单句、整集、全部课程四个互斥文字选项，不增加首页或播放器按钮。全部课程从所选句播放到本课结尾，再从下一课第一句继续，末课回到首课。原句、Drill、2–5 遍和留白设置沿用。进度与系统媒体元数据仍描述当前课程的任务。

开启时复制首页课程顺序，搜索不参与队列；刷新不会重排队列，后续下载仍使用最新目录中的课程包版本。只有一个下一课预下载任务，不预下载整个目录。课程缓存和下载校验沿用既有 25 MB / 100 MB 预算，下载互斥按课程隔离，避免另一课的预下载阻挡手动选择。取消时检查协程状态，保留完整课程包校验与原子安装。

上一句／下一句短按切句，长按约 450ms 切到上一课／下一课首句。一次按住只触发一次，松手不追加切句，触发前移出可取消；保留暂停状态并沿用当前练习模式。首尾句仍可长按，全部课程范围首尾衔接，其他范围停在课程边界。提供有明确名称的无障碍切课操作；设置内只有一行低强调操作提示。

播放会话与阅读页可见状态分别保存。全部课程时返回首页继续收听，首页保持原有列表和留白，不增加迷你播放器；可用系统媒体卡片控制播放，点回正在播放的课程直接恢复阅读。统计页、前后台与 Activity 重建不会因自动换课强制打开阅读页。手势返回按阅读会话身份完成，既保护新的手动打开请求，也允许背景课程在手势期间继续播放。

自动切课先尝试预下载结果，再按固定顺序有界遍历，已不可用课程在本次连续播放中跳过；遍历一轮均不可用时停止。跳过提示不在每一课重复显示，手动播放或手动切课可重新尝试。切课下载期间暂停会保留到新课程，切课请求可被后续操作取消。

跨课不会重新跑封面展开：阅读容器保持全尺寸，播放器不退出，内容以 8dp 以内的轻微位移与透明度交接。减少动态效果时直接更新。按压缩放、内容交接只在绘制图层读取动画值，不每帧重组列表，不增加模糊过滤区域。课程顺序仅在启用、刷新或用户操作时处理，不由音频位置逐帧重建。

云端验证覆盖方向与首尾边界、快照顺序、失败遍历上限、后台跨课、暂停中的切课、Drill 设置保留、长按阈值/取消/长时间按住与无障碍动作、播放器位置和新课程首句。[构建 42742831152](https://github.com/laughingxyw-arch/Rachels_English/actions/runs/42742831152)（源码 6b985d8）通过 Release 编译、Lint（无错误）、53 项单元测试、28 项原生模拟器回归与签名校验。返回落地点击覆盖普通返回及预测返回后立即打开同课、另一课；离场播放器移除命中节点，保持原有视觉交接。后台接续测试从课程开头启动，进入后台后才定位结尾，避免测试准备期间已自然跨课。未在开发电脑安装 Android SDK；小米 15 / Android 16 的 120Hz 真机帧时间未验证。
