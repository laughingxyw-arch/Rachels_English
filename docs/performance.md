# 120Hz 动画与交互验收

用户要求所有动画和交互以小米 15 / Android 16 的 120Hz 体验为目标，避免掉帧。120Hz 的标称帧间隔为 8.33ms；应用侧 CPU、RenderThread 和 GPU 工作应留有余量，不能把 60Hz 的 16.67ms 当作通过标准。

## 真机测量

- 使用正式签名的 Release 或与 Release 优化设置一致的性能构建，在小米 15 上测量。记录版本、提交、Android 版本、实际刷新率、温度与省电状态。
- 确认操作期间实际显示刷新率为 120Hz。屏幕支持 120Hz 或平均 FPS 接近 120 都不能替代逐帧结果。
- 使用 Perfetto FrameTimeline 检查帧 deadline 和 jank，并关联主线程、RenderThread、GPU、布局及垃圾回收；Macrobenchmark 的 FrameTimingMetric 可记录 CPU 帧耗时和 deadline overrun。
- 分场景报告样本数、P50 / P95 / P99、最大耗时、deadline 超时帧和卡顿率，目标是测试操作中没有应用引起的超时/掉帧。区分系统或 SurfaceFlinger 卡顿，不静默删除异常样本。
- 冷启动、首次解码、缓存命中和持续操作分别测量；每个常用操作至少重复 20 次，再检查持续操作后的热状态。声明覆盖范围，不能用一次通过承诺所有设备和系统状态下零掉帧。

## 必测操作

- 首页快速滚动、点击课程、阅读页返回；分别覆盖封面可见与已滚出屏幕。
- 返回手势缓慢拖动、快速松手、中途取消，以及恢复过程中再次拖动。
- 播放器弹出与收回、暂停/继续、连续切句、Drill 模式和次数切换。
- 设置面板打开、拖动关闭、展开复读次数及显示辅助。
- 播放中滚动、文字跟读轨迹、播放器背景模糊和轻提示同时出现。
- 切换减少动态效果、减少透明效果、高对比度和省电模式，检查响应与视觉回退。

## 实现与回归要求

- 网络、音频文件准备、封面解码和校验不阻塞主线程；缓存解码结果。
- 高频动画状态尽量在布局或绘制阶段读取，避免让每次音频进度更新触发整页重组；缓存文字测量和不变绘制资源。
- 检查共享转场的每帧重测量成本，尤其是 animated placeholder 对列表及相邻课程布局的影响。
- 背景模糊只过滤可见浮动表面，复用图形层和滤镜；检查来源图层的重复录制、过度绘制及面板过滤面积。
- 优先优化实测热点；必要时简化光影和模糊复杂度，保持可读性、空间连续性和手势响应。
- 不通过缩短动画、隐藏功能、强制忽略系统省电或减少动态效果设置来掩盖性能问题。

## 当前验证状态

2.1.15 已通过云端 Release 编译、Lint（无错误）、47 项单元测试与 22 项原生模拟器回归（构建 37304394418，源码 bd28ea6）。新增回归验证本机累计值不被较旧保存任务覆盖、缓存仅用于对应恢复身份；生产 API 与合并测试验证重试、身份隔离、恢复后的跨安装累计及有效学习门槛。同步每分钟尝试一次，并在前后台、暂停和结束时补传；网络与数据库操作在 IO 调度器执行，首次身份持久化在后台完成后才开始同步。记录日历使用同步完成的快照，不订阅音频逐帧进度。云端设置复用现有面板的原地展开、减少动态效果分支和可见表面过滤范围，未增加全屏模糊。预算句调整只改变课程 Drill 切片，普通连续音源不变。已核对设置截图；小米 15 / Android 16 的同步期间交互帧时间、设置展开及预算句切点听感均未验证，不能宣称稳定 120Hz 或零掉帧。

2.1.14 已通过云端 Release 编译、Lint、44 项单元测试和 21 项原生模拟器回归（构建 37299167972，源码 3aac22f）。原生回归确认同一连续文件跨句及整集循环不增加音频装载次数，系统拖动和留白切换保留暂停状态；切句前后卡片高度差不超过 0.5px。刷新检查覆盖回弹中再次拖动、真实网络请求在冻结界面时钟期间完成、收回位移回到阈值的 1% 以下及“已是最新”提示。已核对无遮挡阅读页和设置截图，这些功能与像素断言不代表帧时间验收。切句提示在现有行中保留几何位置，通过图形层透明度交接；卡片背景颜色在绘制阶段读取，不引入每帧高度测量。自动跟随仅移动溢出距离，用户拖动/惯性滚动时让出控制。刷新拖动直接更新位移，释放时才创建阻尼弹簧；新拖动取消弹簧并从当前位置继续，刷新图形仅在自身 Canvas/图形层读取旋转和位移，不增加模糊范围。连续音频每个任务只准备一次，句子归属二分查找；时间轴按任务预计算，跨句不重建播放器或音频文件。学习采样沿同一文件位置计量，系统拖动重置采样锚点，暂停与换模式保留既有统计口径。需真机检查原音连续听感、刷新回弹、切句跟随及 120Hz 帧时间，均未验证。

2.1.13 已通过云端 Release 编译、Lint、41 项单元测试及 20 项原生模拟器回归（构建 37289536231，源码 c583470）。新增功能回归覆盖统计横向滑动及快速反向操作、返回手势取消及落地点击、下拉刷新阈值与松手触发。最终截图受到模拟器 Pixel Launcher 未响应弹窗遮挡，完整视觉验收未完成；通过的交互断言不作为真机帧时间或视觉性能证明。首页与统计页的连续位移、背景缩放在图形层读取进度；记录页离场完成的同一帧恢复首页触摸与语义，返回取消从当前位置恢复。热力图与日期分别使用横向 Pager，每侧最多预组合一页，日期明细高度依据快照缓存以避免翻页高度跳动；音频更新不驱动日历。下拉刷新采用嵌套滚动，内容位移只在图形层读取，阈值反馈仅在跨越时发出；原地设置展开的布局更新仅限当前面板。首页和记录页分别复用独立采样图层，记录页在位移/缩放外层记录，使采样原点稳定并保留子层变换；避免两个场景重录同一层及转场内容串画面。无新增全屏模糊过滤或逐帧日期/课程汇总。需真机覆盖连续左右滑动、反向返回、设置展开和下拉刷新；120Hz 稳定性未验证。

2.1.12 已通过云端 Release 编译、Lint、41 项单元测试及 18 项原生模拟器回归。新增回归实际将 Activity 置于后台，累计至少 61 秒有效听音，确认达标记录写入本机数据库；暂停与拖动不虚增时长，原句及 Drill 整集循环均回到第一组，独立页面隔离底层无障碍节点与点击。学习计时以 500ms 低频采样实际音频位置，在暂停、切段、跳转与进入后台前结算；不订阅逐帧跟读动画状态。SQLite 在 IO 调度器上保存，每十秒只写入变化的日/课程记录，暂停及离开时提前保存；日历使用进入页面时的有效记录快照，与播放器帧更新隔离。热力图最多绘制三个月格子，不增加全屏模糊、逐帧文字测量或共享元素重布局。需追加真机日历点击、历史浏览、循环展开与长期后台听音场景。小米 15 / Android 16 的 120Hz 真机帧时间未验证。

2.1.11 已通过云端 Release 编译、Lint、33 项单元测试及 16 项原生模拟器测试。新增系统媒体回归确认平台媒体控制器收到课程封面、完整任务时长与拖动定位能力，后台位置有效；Drill 复读保持同一任务身份，暂停时定位到音频或留白保持暂停，末尾与结束后当前组循环定位正确。封面处理复用缓存并在 IO 调度器解码、缩放和压缩，最大边长 512px；时间轴位置查询为 O(1)，定位使用二分搜索，元数据仅按状态变化更新，不增加每帧通知重建。页面动画、布局与材质没有新增计算。小米 15 / Android 16 的系统卡片最终布局及 120Hz 真机帧时间未验证。

2.1.10 已通过云端 Release 编译、Lint、30 项单元测试及 15 项原生模拟器测试。明暗与高对比度配色中的正文、辅助文字和强调色在背景、卡片及选中背景上均通过 4.5:1 对比度检查。新增原生回归在真实播放与设置面板打开期间连续切换系统主题，确认 Activity 不重建、课程与播放任务保持、面板不关闭，并检查状态栏图标与导航手势条的明暗标志。已核对暗色首页、阅读页、设置与高对比度截图，阅读页暗色手势条可见。系统栏使用回调传入的配置，避免读取尚未更新的 decor 资源。配色与 Material 色板按主题及对比度变化缓存，颜色切换直接更新当前界面，不增加全屏过渡、模糊范围或逐帧布局；跟读轨迹和播放器文字缓存继续复用。原有后台播放与界面回归继续通过；小米 15 / Android 16 的 120Hz 真机帧时间仍未验证。

2.1.9 已通过云端 Release 编译、Lint、28 项单元测试与 14 项原生模拟器测试。新增回归覆盖页面进入后台后跨句继续播放、媒体控制暂停/切句/继续、Activity 重建保留同一任务，以及熄屏 Drill 穿过跟读留白进入下一次复读。媒体会话仅在任务状态与切段时更新，音频进度使用实时位置供应器，不随 32ms 界面进度重建通知；后台进度轮询降至 100ms，留白以单调时钟截止时间计时并仅在必要期间持有带超时的唤醒锁。音频启动排在前台通知提交之后，暂停、停止与切段会取消尚未执行的启动。动画、共享元素、布局与材质绘制没有新增计算；原有 12 项界面与播放回归继续通过。小米 15 / Android 16 的后台省电策略与 120Hz 真机帧时间仍未验证。

2.1.8 已通过云端 Release 编译、25 项单元测试和 12 项原生模拟器测试。新增播放器模式滚轮回归覆盖中间位置、连续点击保持向下运动、48dp 点击高度，以及设置行按住前后的背景像素一致。滚轮文字布局缓存复用，位移只在绘制阶段读取，减少动态效果时直接切换；不增加模糊过滤范围。恢复阅读位置在首次列表布局前确定；逐帧回归覆盖首次布局、完整进入转场及结束后的稳定位置，不出现顶部到上次句子的二次滚动，随后播放换句仍能自动跟随。新增真实坐标触摸回归在返回落地的首个可见帧点击课程，覆盖按钮/侧滑返回后立即进入同一课程及另一课程；加载竞争回归覆盖新请求仍在等待和同一课程新实例已完成两种情况。目标页面触摸层级只随导航目标改变，不增加逐帧计算。新增回归逐帧检查 Tower Bridge 共享标题保持一行、进入与返回途中时长标签具有中间透明度，并验证真实音频切段后总任务进度保留、单句与无限循环不暴露进度条。任务时间轴按音频与留白预计算，进度查询为 O(1)；标签透明度和播放器填充动画在图形层/绘制阶段读取，不增加模糊过滤范围。

上一版返回交接前后可见容器高度差不超过 1px、设置背景缩放、手势取消/重新拖动与材质像素回归继续通过。数学测试保留 60Hz / 120Hz 的弹簧末帧采样。尚未获得小米 15 的真机帧时间记录，**120Hz 稳定性未验证**；数学与云端模拟器检查不作为真机性能验收。
