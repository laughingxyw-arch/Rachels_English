# 学习记录同步

统计保存在本机 SQLite，并自动同步到独立 Cloudflare D1。课程网页与课程包公开，统计 API 需要个人恢复码才能访问；学习记录和恢复码不进入公开仓库或静态文件。

每次安装生成随机设备标识和 256 位恢复码。设置 → 云端同步可复制恢复码、立即同步或恢复。恢复码等同于访问凭据，需保存到手机以外；分享恢复码会允许对方访问该份记录。重装后输入原恢复码，找回已同步记录。无法联网时继续本地计时，联网启动、前后台切换、暂停/结束及每分钟尝试补传。未同步的本机数据随卸载仍可能丢失。

每个安装独立累计日/课程的听音与跟读时长，云端按设备、日期和课程保存最大累计值。重试、较旧请求和本机缓存不会重复增加统计；各安装的累计值相加后，才应用同一天同课程听音满 60 秒的有效学习门槛。恢复的旧安装记录与当前安装增量分开保存，避免把恢复总数重新上传为新增时长。现有本机记录作为当前安装累计值保留。

恢复时先读取既有云端身份，验证成功才上传本机累计值并切换恢复码；错误恢复码不创建空账号。云端计数在后台线程下载并事务缓存，缓存绑定对应身份。日历仅在同步完成时刷新快照，与播放进度隔离。无自定义逐帧同步动画或新增背景模糊。

接口：`/api/study`，HTTPS Bearer 恢复码；服务端只保存恢复码的 SHA-256 身份索引。响应禁止缓存；不提供公开列举、跨身份读取或无需凭据的查询。上传每批最多 100 行，严格验证日期、课程标识、设备标识与整数时长；读取按 1000 行分页。D1 迁移及 Functions 部署由课程发布工作流维护。

小米 15 / Android 16 的 120Hz 真机性能未验证。
