# 学习记录同步与恢复

统计保存在本机 SQLite，并自动同步到 Cloudflare D1。课程和课程包公开；学习记录需要认证，不进入公开仓库或静态文件。

2.1.18 使用 Android Credential Manager 通行密钥。已由私有管理流程确认归属的现有安装，可用其原有凭据直接请求系统保存通行密钥。没有旧安装凭据时，首次通过私有的一次性关联链接，将历史身份绑定到系统保存的密钥。链接只保存到期、一次使用的随机能力凭据，其哈希存于云端，不内置公开 APK。绑定后，重装启动会尝试调用系统凭据窗口，验证后恢复；设置 → 云端同步也可重试。不输入恢复码，不使用手机唯一 ID 作为身份凭据。首次关联必须保留原始云端数据备份，只按明确授权关联身份；开发测试记录不并入真实统计。

系统凭据提供者负责保存私钥、确认指纹或其他设备解锁方式；应用和服务器不接收指纹。Xiaomi 与 Google 等提供者的支持、初次启用和跨设备同步取决于手机系统与账户配置，不能仅凭 Credential Manager API 或浏览器测试承诺真机可用。独立验证 APK 使用不同包名、不同通行密钥身份和一条虚拟记录，可先验证卸载重装，不加载真实学习记录。

服务端要求 ES256、发现型密钥和用户验证，校验挑战、RP、网站或正式签名 APK 的来源、签名及计数器。挑战五分钟、一次使用；私有初次关联能力默认七天且一次使用。有效验证签发 30 天随机会话，服务器只存会话哈希。过期会话返回 401，不会退化成新账号；本机缓存保持可见，验证后补传。系统可提供指纹以外的解锁方式，应用不强制绕过系统选择。

每次安装保留独立随机设备分片。每个分片按日、课程独立累计听音与跟读时长，云端取最大累计值；重试和乱序请求不重复增加统计。不同安装累加后才应用同一天同课程听音满 60 秒的有效学习门槛。恢复只下载旧分片，上传本机增量，不把云端总数再上传成新增时间。缓存绑定稳定账户标识，独立于会话轮换。网络及数据库处理在 IO 调度器执行，日历只在快照更新时刷新。

离线继续本地计时；联网启动、前后台切换、暂停/结束及每分钟补传。未成功同步的本机数据随卸载仍可能丢失。既有版本的恢复凭据继续用于旧安装上传；明确配置的私有身份别名将历史安装上传关联到同一账户，原记录保留，不开放公开认领接口。

接口：`/api/study`（HTTPS Bearer，单批最多 100 行、读取每页 1000 行）、`/api/passkey/register/options`、`/api/passkey/register/finish`、`/api/passkey/authenticate/options`、`/api/passkey/authenticate/finish`。通行密钥接口仅接受 POST、限制输入体积且禁止缓存。域名关联通过 `/.well-known/assetlinks.json` 声明应用包名和签名证书。首次关联链接在 URL fragment 中携带能力值，不放查询参数；页面不加载第三方资源；保留片段以支持刷新，并在当前标签页的 sessionStorage 临时保存绑定信息 30 分钟，不放入查询参数或永久本地存储。

发布需先完成 D1 迁移再部署 Functions 和静态域名关联文件。GitHub 工作流仅在配置 Cloudflare 部署凭据时执行部署；缺少凭据时，需使用已授权本机 CLI 部署并实测线上接口，不能将内容检查通过当作部署完成。

小米 15 / Android 16 凭据提供者兼容性、真实指纹与卸载恢复、120Hz 真机性能均未验证。

首次关联网页提供「保存通行密钥」，通过同源 WebAuthn 注册到系统凭据服务，不依赖浏览器唤起 App。网页仅在内存中持有待确认注册响应；确认网络失败时重试同一响应，成功后清除片段和临时绑定信息，不在浏览器保存会话令牌。随后从桌面进入 App，在云端同步中「验证并恢复」。网页与 App 共用 RP ID，凭据是否跨浏览器和原生可见取决于所选系统提供者，仍需真机验证。应用跳转作为次要入口保留，不能用网页 DOM 或 Intent 解析测试替代实际唤起验证。

本次已用实际网页按钮、浏览器虚拟平台验证器和隔离数据库验证：取消不消耗绑定、确认请求断网后不重复建钥、新客户端重新验证并读回既有学习记录。该测试不接触生产身份，也不证明小米凭据服务已通过。

浏览器入口不可用时，单人部署可通过专用初始化 APK 在 App 内完成第一次注册。绑定值从 Actions Secret 注入，仅进入专用 Release；普通 Release、Debug 和公开 GitHub Release 均不含此值。专用工作流必须先验证相同源码的标准 Android 回归成功，关闭构建缓存，上传前使用独立密钥 AES-256-GCM 加密，解密密钥不进入工件或仓库；安装包只通过私有、不可猜测的下载地址交付。该能力仍受服务端限时及一次性使用约束，不开放匿名认领旧记录。首次启动先尝试恢复，明确没有凭据时才注册；取消、校验失败、网络错误和已关联安装不重新注册。初始化失败在 App 内提示，手动重试使用现有云端同步入口。

临时安装包只在用户明确授权后，通过 `--include-private-setup` 显式加入独立预览部署，默认内容构建排除它，不改公开站点。下载路径使用 256 位随机能力值，不写入公开页面、目录或脚本；`private_installs` 仅保存下载能力与初始化授权的哈希。下载函数在读取静态 APK 前验证两者均未过期且初始化尚未使用；缺失或失效返回 410，数据库故障返回 503，不回退到静态文件。响应强制 no-store、no-referrer 和 noindex。绑定后停止下载，并清理临时部署；用户私有 URL 不进入 Git 或公开发行说明。
