# 连续音源制作与分发

每课保留已确认的完整对白母音频，在同一时间轴上标记句子和短语。单句、Drill 的切片保留独立重放需要的首尾留白和已验证尾音；连续版本直接从母音频截取，保持原有暂停、重叠和语速，不拼接切片，不逐句淡化、补静音或去静音。发布格式保持 48kHz、双声道、16 位 PCM WAV。

`site/scripts/export_continuous.py` 接受课程 ID、本地母 WAV 与时间偏移。偏移表示教材时间零点在母 WAV 中的位置；例如 Booksmart 的教材零点对应母音频 9.54 秒。Booksmart 和 Tower Bridge 制作脚本已自动调用它，新增教材复用同一函数。

连续文件保存到 `audio/<课程 ID>/continuous.wav`，教材的可选 `continuous` 对象记录相对路径、教材坐标下的 sourceStart、实际采样时长及 SHA-256。句子 start 严格递增；对原对白重叠位置，不重复任何采样。独立切片的 end 可以重叠，连续播放的视觉归属在下一句 start 交接。

`scripts/build_content.py` 把连续 WAV 与教材一起纳入不可变课程包，并计算课程版本。`scripts/check_content.py` 校验音频引用、校验和、PCM 格式、采样时长、完整时间轴覆盖与句序。课程更新仍由首页同步获取，用户打开课程时下载，旧客户端忽略新增字段继续播放切片；旧缓存及无连续音源的离线课程仍可使用。

普通整集、关闭留白且未选择单句循环时，Android 只准备一个连续文件。点击句子或系统拖动直接定位文件；UI 在原时间轴上选择句子，进度表示本次剩余任务。整集循环定位回同一文件的开头。单句循环、Drill 与留白跟读继续使用干净切片。切换循环/留白时保留播放位置和暂停状态。

100 课不全部内置到 APK。本次仅把 Tower Bridge 连续版更新到既有离线示例，其他课程按需缓存；不压缩、降低采样率或改变既有切片。

当前三课新增连续 PCM 总计约 11.2 MB（十进制）；压缩下载包增量与 WAV 的内容可压缩性有关。母音频和原视频仍留在不追踪的 downloads，公开的只有选定对白与封面。
