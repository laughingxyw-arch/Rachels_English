# Booksmart 教材 · 2026-10-04

来源：[Speaking English | How to Understand Native Speakers](https://www.youtube.com/watch?v=hLgMIwFeE88&t=7868s) 的 Booksmart 章节（02:11:08）。教材只保留章首电影对白，约 17.33 秒；前面的访谈、老师过场和分析不进入原句音频。封面来自这段电影画面的双人镜头，保留画面中的来源标识。

7 个句子组，13 个练习切片，另有一份连续原音。班级规定、男声感叹和快速预算句各分成两段，其余对白保持完整。预算句参考老师对 “I need to go over the” 和 “end of the year budget numbers we have” 的分段讲解（约 02:26:05–02:28:10），保留两个较完整的练习意群：

1. Anyway, I need to go over
2. the end-of-the-year budget numbers we have.

这是结合老师讲解的较粗分段，不逐一复制其重音、弱读分析的小片段。切点设在 over 后，保留 the 与 end 的连读，不从两词中间切开。Drill 依次播放每段三遍、整句三遍；短句整句三遍，共 39 次、约 121.37 秒。客户端仍可选择 2–5 遍和留白跟读。

中文翻译默认关闭；每句仅保留一两条简短的弱读、连读或重音提示。文字根据章节字幕、老师讲解与两种独立识别结果核对；低声男声中的犹豫起句保留在对应句组。

## 音频整理

- 本地下载和原始教学音频留在被忽略的 `downloads`，只提交教材需要的原声切片和电影截图。
- 转封装保留了前一音频块，实际开场文件比请求的截取时间更早。因此采用字词对齐选择边界，不把下载请求时间直接当作音频文件零点。
- CTC 和 Whisper 辅助定位；对预算句末尾、Nick、Really 与老师独立重放进行归一化波形相关校验，相关值分别约 0.994、0.998、0.999。
- 原句避开下一句声起；切片添加 80ms 前留白、120ms 后留白及 3ms 边缘渐变，减少点击声。自动识别对低声、高音及快速弱读存在替词，不能单凭识别结果保证听感或声学边界完美。
- [生成脚本](../site/scripts/build_booksmart_lesson.py) 保留分段选择，输入为本地开场 WAV。课程在现有 JSON 结构下兼容 Android 2.1.11，不新增客户端代码或重编译 APK。
