# 原声练习 2.1.15 · 学习记录同步与 Drill 修正

新增学习记录自动云端同步与本地缓存。使用设置中的恢复码，可在重装后找回已同步记录；恢复码需另行保存。离线继续记录，联网后补传；尚未同步的本机记录仍可能随卸载丢失。同步不会公开学习记录，也不会改变有效学习的计量口径。

Booksmart 的快速预算句改为两个意群各复读，再复读整句。参考老师的分段讲解，保留 the end 连读；普通播放的连续原音不变。

同步以每次安装的累计值合并，重试不会重复计时。同步和缓存写入在后台线程执行，日历仅在同步完成时更新快照。云端 Release 编译、测试与真机性能状态将在验证后补充；小米 15 / Android 16 的 120Hz 帧时间未验证。
