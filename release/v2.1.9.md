# 原声练习 2.1.9

本版修复熄屏、切换应用后音频暂停的问题。原句连播和 Drill 复读通过 Android 媒体前台服务保持播放，锁屏与通知栏支持暂停、继续及上一句／下一句；点击通知可回到正在练习的课程。

- 播放会话独立于页面生命周期，恢复应用与页面重建继续使用同一播放任务。
- Drill 间隔与跟读留白使用单调时钟计时；留白期间仍保持媒体会话，暂停后保留剩余时间。仅播放与必要的留白期间保持 CPU 唤醒，停止与暂停立即释放。
- 耳机断开与音频焦点丢失继续暂停。主动返回课程首页仍结束当前练习。
- 延续播放器模式滚轮、设置无灰色点击底色、首次恢复阅读位置与返回连续转场。

验证：发布前执行云端 Release 编译、Lint、单元测试、原生模拟器回归与 APK 签名检查；结果在发布说明中补充。新增覆盖后台跨句播放、媒体控制、Activity 重建及熄屏 Drill 跨留白复读。

兼容 Android 8 及以上；目标 Android 16。小米 15 的 120Hz 帧时间与厂商省电策略尚未真机验证。
