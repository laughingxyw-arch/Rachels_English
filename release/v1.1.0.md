原声练习 1.1.0 是 Android 界面与交互更新。课程内容继续独立从云端同步，无需因新增课程重新安装应用。

### 本次更新
- 首页封面与课程页缩略图建立共享元素转场，让进入和返回课程保持空间关联。
- 模式选择使用连续移动的选中底板；按钮采用可打断的弹簧反馈。
- 设置面板支持向下拖动关闭，中途松手可自然回弹；保留键盘与按钮操作。
- 统一网页与 Android 应用图标，使用分层声波符号、柔和渐变和克制的高光；Android 保留自适应图标层及单色图层。
- 尊重浏览器减少动态效果设置，并读取 Android 系统动画关闭设置。
- 发布采用明确的版本名称、固定递增的 Android 版本代码与版本化安装包名称。

### 安装与兼容性
- Android 8.0 及以上；目标 Android 16。
- 与 1.0.0 使用同一应用 ID 和签名，可直接覆盖安装。
- 内置 Jaafar Jackson 与 Tower Bridge 两门课程，支持离线播放；获取新课程需要联网。
- 中文翻译默认关闭。保留原句、三遍 Drill、循环和留白跟读。

### 验证与限制
- 发布构建执行 Android Release 编译、Lint 与 APK 签名验证。
- Web 界面检查移动端布局、共享元素、键盘操作及减少动态效果；课程包校验音频引用与 SHA-256。
- 共享元素转场取决于设备 WebView 支持；不支持时直接进入课程。小米 15 / Android 16 真机手势与视觉效果仍需安装后确认。
- 本次为前台练习应用，不提供后台音频播放或系统媒体通知。
