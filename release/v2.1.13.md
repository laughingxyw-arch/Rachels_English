# 原声练习 2.1.13

收起冗余控制，让设置、统计浏览和课程刷新通过直接操作完成。

- 更多设置在练习面板中原地展开，中文翻译、发音提示和显示辅助不再跳转独立页面；统计页设置采用同一套底部面板。
- 统计页移除四个翻页按钮、深浅图例和规则说明。热力图区左右滑动浏览三个月窗口，日期明细区左右滑动切换一天，也可点选日历格子。
- 首页只保留学习记录入口。列表顶部下拉达到 72dp 内容位移后，松手刷新；未达阈值回弹，跨过阈值给予轻触反馈，完成后收回且不弹成功提示。
- 首页和学习记录使用连续横向位移，系统返回手势跟随操作进度，支持取消和反向恢复；设置面板背景缩放保持连续。

有效学习的后台统计口径与本机记录保持一致，现有课程缓存、设置与记录保留。正式包使用原有签名，可覆盖安装。

验证：云端 Release 编译、Lint（无错误）、41 项单元测试及 20 项原生模拟器回归通过。新增回归覆盖原地展开设置、统计滑动与反向滑动、返回手势取消和落地后立即进入课程、下拉刷新阈值及松手触发。APK 校验和一致，签名与既有版本相同，源码与安装包的个人标识扫描通过。

最终构建的截图受到模拟器 Pixel Launcher 未响应弹窗遮挡，不能作为完整视觉验收；交互断言与先前未遮挡截图仅用于功能核对。小米 15 / Android 16 的 120Hz 真机帧时间未验证。
