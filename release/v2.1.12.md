# 原声练习 2.1.12

新增本机学习记录与互斥循环范围，保持播放器操作简洁。

- 循环范围：在练习设置中选择关闭、单句或整集。原句与 Drill 独立决定练习方式；单句 Drill 重复该句完整的分段及整句复读，整集播放完后回到第一句。默认从所选句子播放至课程结束。
- 学习记录：首页日历入口展示本月有效分钟数与近三个月蓝色热力日历。点选日期查看有效分钟数和课程名称，并可继续练习；历史月份可浏览。
- 统一统计口径：同一天、同一课程累计实际听音达到 60 秒才算有效学习，达标后纳入当天该课听音及跟读留白。静音、暂停、加载、跳转和普通复读间隔不计时；后台听音照常累计。
- 独立设置页：集中中文翻译、发音提示、显示辅助与统计口径，练习面板保留循环、复读次数和跟读留白。

记录仅保存在本机，从安装此版本后开始累计；更新保留现有课程缓存与偏好。Android 8.0 及以上可安装。

验证：云端 Release 编译、Lint（零错误）、41 项单元测试与 18 项原生回归全部通过。后台实际听音满一分钟、本机保存、暂停/拖动不虚增时长、原句/Drill 整集循环和页面隔离均通过检查。小米 15 / Android 16 的 120Hz 真机帧时间尚未验证。
